# Development notes

Repository `0xPunisher/0xPunisher` is the GitHub profile repo: `README.md` in the root is shown on the profile page. That is why `README.md` holds only visitor content, and all dev notes live here.

## Structure

```
README.md                    profile content (header, link buttons, stats)
assets/header.svg            animated profile header card
assets/btn-x.svg             pill button: X, @0x_Punisher
assets/btn-crawlscan.svg     pill button: crawlscan.fun
assets/stats.svg             live stats: numbers card (generated by CI)
assets/languages.svg         live stats: top languages card (generated by CI)
assets/activity.svg          live stats: contribution grid card (generated by CI)
scripts/svgkit.py            shared fonts, palette, subsetting, size check
scripts/build_assets.py      generator for the static SVGs (header, buttons)
scripts/build_stats.py       generator for the three stats SVGs
.github/workflows/stats.yml  daily job that rebuilds and commits the stats SVGs
requirements.txt             Python dependencies (pinned)
.env.example                 template for the local .env with the token
preview.html                 local preview on GitHub dark and light backgrounds
NOTES.md                     this file
```

## Rebuilding assets

The SVGs are generated, do not edit them by hand. Change `scripts/build_assets.py` and run:

```
pip install -r requirements.txt
python3 scripts/build_assets.py
```

The script downloads the fonts into `scripts/.fonts/` (git-ignored), builds the SVGs and fails if any file goes over 150 KB.

To preview: `python3 -m http.server` in the repo root, then open `http://localhost:8000/preview.html`.

## Live stats

`scripts/build_stats.py` builds `stats.svg`, `languages.svg` and `activity.svg` from the GitHub GraphQL API for user `0xPunisher`.

What is counted:

- Stars earned, repositories, languages: only repos owned by `0xPunisher` that are not forks. Private repos are included when the token can see them.
- Commits 12 mo and contributions 12 mo: `contributionsCollection` for the last year (same numbers as the profile calendar).
- Streaks: computed from the daily contribution calendar. The script walks back year by year to the account creation date, so the longest streak is all time. The current streak does not break until a full day passes with zero contributions (an empty today still counts as "in progress").
- Languages: bytes per language summed over all own non-fork repos, top 6 shown, percent of all bytes.
- Activity grid: 53 week columns (Sunday on top), the last column ends today. Five levels: empty day is dark gray, active days are split by quartiles of the year's non-zero counts and blend from dark gray to `#e5383b`.

Token:

- Name: `GH_STATS_TOKEN`. In CI it is the repo secret (Settings, Secrets and variables, Actions). Locally it goes into `.env` in the repo root (copy `.env.example`). `.env` is in `.gitignore`, never commit it: this repo is public.
- Classic personal access token with scopes `repo` (private repos and their languages) and `read:user`. With no scopes at all it still works, but only public data is counted.
- The built-in Actions `GITHUB_TOKEN` is not enough: it only sees this one repo.

Run locally:

```
pip install -r requirements.txt
python3 scripts/build_stats.py --demo   # made-up data, no token, no API calls
python3 scripts/build_stats.py          # real data, reads GH_STATS_TOKEN from .env
```

Without a token and without `--demo` the script prints a short error and exits with code 1.

The stats SVGs in the first commit are demo output; the first workflow run replaces them with real data. Do not commit demo output over real stats after that.

CI (`.github/workflows/stats.yml`): runs daily at 03:17 UTC and on manual dispatch, installs `requirements.txt`, runs `build_stats.py` with the secret and commits `assets/*.svg` as `github-actions[bot]` only if git sees a change. Every card shows "updated YYYY-MM-DD", so in practice there is one small commit per day.

Animations in `activity.svg`: today's cell breathes with a red outline and a soft expanding ring; a thin red scanner line with a faint trailing glow moves left to right, 10 s loop. Both turn off under `prefers-reduced-motion`.

## GitHub constraints and how they are handled

- README sanitizer strips CSS and JS, so the whole design lives inside SVG files.
- SVG is rendered via `<img>`, so links inside it are not clickable. Each button is a separate SVG wrapped in `<a href>` in README.
- SVG as an image cannot load external fonts. Fonts are embedded as base64 WOFF2 in `@font-face` inside each SVG.
- CSS animations inside SVG do work and are used for the typing line, cursor, status dot and scanner line.

## Design decisions

Palette (dark, strict, scanner/terminal theme):

| Role        | Color     |
|-------------|-----------|
| Background  | `#0a0a0a` |
| Thin lines  | `#1f1f1f` |
| Main text   | `#e8e8e8` |
| Muted text  | `#7a7a7a` |
| Accent      | `#e5383b` |

The red accent is used sparingly: the "0x" in the title, prompt sign `>`, the "online" dot, the scanner lines, the top language bar and the activity grid.

The card has its own background and rounded corners, so it looks the same on both GitHub dark (`#0d1117`) and light (`#ffffff`) themes. The header viewBox is 1000 x 340 and is stretched to 100% width in README.

Fonts (both SIL Open Font License, from google/fonts):

- Space Grotesk: Bold 700 for "Punisher" in the big title, Medium 500 for the column values and stats numbers.
- JetBrains Mono: Bold 700 for "0x" in the title, Regular 400 for all other monospace text.

Title "0x": in Space Grotesk the zero looks like the letter O, so the title read as "OxPunisher". "0x" is set in JetBrains Mono (dotted zero) in the accent color. Its size is scaled so the cap heights of both fonts match on one baseline, and each glyph is placed by its ink bounds with a 6 px gap, so the two parts read as one word.

Why subsetting: the variable TTF files are about 140 KB and 190 KB, base64 adds another third, and one SVG would carry several faces. The script pins each variable font to a static weight, then subsets it with fonttools to only the characters that SVG actually uses, and saves as WOFF2. Result: the header is about 17 KB, buttons about 3 KB each. Embedded font family names are prefixed (`PX Mono`, `PX Display`, `PX Text`) so they never collide with locally installed fonts.

Animations are calm on purpose:

- Tagline types once, letter by letter (steps timing), then the cursor fades in and out smoothly.
- Status dot breathes and emits a soft expanding ring.
- Scanner: thin red line with low opacity and a faint glow passes top to bottom, 6 s loop.
- `prefers-reduced-motion` turns animations off and shows the final state.
